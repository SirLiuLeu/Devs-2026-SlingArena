3️. CORE SYSTEM PIPELINES
A. CHARGE & LAUNCH PIPELINE
Client:

Send StartCharge

Send ReleaseCharge

Server:
OnStartCharge(player):
    PlayerState.IsCharging = true
    Record ChargeStartTime

OnReleaseCharge(player):
    ChargeTime = clamp(now - ChargeStartTime)
    ChargeRatio = ChargeTime / MaxChargeTime

    LaunchForce = BaseForce × ChargeRatio × SizeModifier
    ApplyImpulse(player.Character, LaunchForce)

    PlayerState.IsCharging = false
B. COLLISION RESOLUTION PIPELINE

Server only.

When character touches another entity:

CollisionService.ResolveCollision(attacker, defender)

Pipeline order:

Validate alive

Validate not invulnerable

Compute ImpactDamage

Apply self-damage

Apply defender damage

Resolve knockback

Apply force decay

C. DAMAGE FORMULA
ImpactDamage =
VelocityMagnitude
× log(Size + 1)
× SlingshotModifier
× DamageMultiplier

Clamp max damage per hit.

D. SELF-DAMAGE RULE

Only active if:

ChargeRatio == 1

SpecialUpgradeActive == true

if ImpactDamage > 1.5 * SelfHP then
    ImpactDamage = 1.5 * SelfHP
end

SelfDamage = ImpactDamage * 0.5
E. KNOCKBACK FORMULA
SizeRatio = AttackerSize / DefenderSize
KnockbackForce = BaseImpactForce × SizeRatio

If SizeRatio < 1:

Reverse direction to attacker

Clamp max knockback.

F. FORCE DECAY

After each collision:

RemainingVelocity *= 0.6

Stop if velocity < threshold.

4️. GROWTH SYSTEM
EXP Gain Sources

Destroy object

Damage player

Kill player

Consume food

Level Formula
RequiredEXP = BaseEXP × (Level ^ 1.3)
Size Formula
Size = BaseSize × (1 + sqrt(Level) × 0.08)

After Level 30:

Size growth reduced by 70%

5️. SKILL SYSTEM
Invulnerability

Config:

Duration = 1s
Cooldown = 10s
MaxUpgradeDuration = 3s
MinUpgradeCooldown = 7s

Activation:

if now > InvulCooldownUntil then
    InvulnerableUntil = now + Duration
    InvulCooldownUntil = now + Cooldown
end

While invulnerable:

Ignore damage

Ignore knockback

Do NOT reset velocity
